Features

A memory that works while you do

Mitthu watches your screen the way a screen reader does — privately — and turns it into something you can actually ask questions of.

🧠

Remembers everything

Apps, window titles, and on-screen text become a private, searchable timeline. "When did I watch that lecture?" — answered.

🔁

Never forget to revise

Watched a study video? Get spaced-repetition nudges after 1, 3, 7, 14 and 30 days — so it actually sticks.

✅

Knows what's due

Bills and deadlines you see on screen turn into tasks with dates. Ask "what's important today?" and get a real answer.

🔌

Plugs into Claude

Connect once and Claude answers from your memory — in the terminal, on desktop, and on the web via a native MCP server.

🔎

Hybrid search

BM25 keyword + vector similarity with reciprocal-rank fusion, rerank, and time filters. Duplicate screens are hashed out.

🔒

Private by design

Everything lives in one SQLite file on your Mac. The server binds to localhost and every request needs a token.

How it works

Up and running in four steps

No accounts to configure, no data leaving your Mac. Install, grant one permission, connect Claude.

  1. 1

    Download & install

    Grab the app from this site and drag it in. Apple Silicon and Intel, macOS 12+.

  2. 2

    Grant Accessibility

    One permission lets Mitthu read window text — the same API screen readers use. Nothing is sent anywhere.

  3. 3

    Sign in with Google

    Used for login only — we never read your email. It just pairs your Mac to the secure tunnel.

  4. 4

    Ask Claude

    Your memory stays on your Mac; Claude reaches it to answer questions and set reminders.

For Claude

Connect once. Ask anything.

mitthuai ships a native MCP server, so Claude Code, Claude Desktop, and the web app treat your memory as a first-class tool.

  • search_memory — hybrid search over your screen history
  • get_timeline — sessions & stats for any day
  • get_important — bills, deadlines & revisions due
  • create_reminder — add a task with a due date
Try asking:"What did I do today?" · "When did I watch that GPU video?" · "What's important today?"
Terminal — connect Claude Code 
claude mcp add --transport http hellomac \
  http://localhost:4789/mcp \
  --header "Authorization: Bearer <your-token>"
🔒

Private by design

Your activity, text, and search index live only on your Mac, in ~/Library/Application Support/HelloMac. mitthuai's servers are just a tunnel — they route Claude's questions to your Mac and the answers back. We don't store your memory and we don't read your email; Google is used solely to sign you in.
